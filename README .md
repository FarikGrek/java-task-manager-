# Консольный менеджер задач на Java

Простое консольное приложение для управления списком дел. Задачи сохраняются в файл и не пропадают после закрытия программы.

## Что умеет

- Добавлять задачи с приоритетом (низкий, средний, высокий)
- Показывать список: сначала невыполненные, внутри по убыванию приоритета
- Отмечать задачи выполненными и удалять их
- Сохранять и загружать задачи из файла `tasks.txt`
- Защита от неверного ввода: пустое название, буквы вместо числа, несуществующий номер

## Как запустить

Нужна установленная Java (JDK 11 или новее).

```
javac -encoding UTF-8 *.java
java Main
```

## Структура проекта

| Файл | Что делает |
|---|---|
| `Main.java` | Меню и ввод-вывод в консоли |
| `TaskManager.java` | Логика: список задач, сохранение и загрузка файла |
| `Task.java` | Модель одной задачи |
| `Priority.java` | Перечисление (enum) приоритетов |
